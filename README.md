# Smart Registration Form

A simple and interactive registration form built using **HTML, CSS, and JavaScript**.  
The form provides real-time input validation and gives users immediate feedback while entering their details.

## 🚀 Features

- User registration form with:
  - Name
  - Email
  - Password
  - Bio
- Real-time form validation using JavaScript `input` events
- Name validation to prevent empty submission
- Email format validation using Regular Expression (Regex)
- Password validation with a minimum of 6 characters
- Bio limited to 200 characters
- Real-time Bio character counter
- Submit button remains disabled until all fields are valid
- Displays appropriate error messages
- Responsive and clean user interface
- DOM manipulation using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Regular Expressions (Regex)
